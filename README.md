# Libra

An open-source, LLM-powered knowledge base that compiles, evolves, and self-maintains.

> Your knowledge, compiled and compounding — not just retrieved.

## Overview

Libra transforms how people manage knowledge. Instead of querying raw documents every time (traditional RAG), Libra uses LLMs to compile ingested sources into structured, interlinked wiki pages that evolve and compound over time.

Inspired by [Karpathy's LLM Wiki pattern](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f).
